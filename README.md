# BeeFitness Store — Tabby & Tamara (Preview)

مشروع متجر BeeFitness بواجهة عربية RTL، وطبقة خادم للكتالوج والسلة ومعاينة الطلبات، مع بقاء بوابات الدفع في وضع المعاينة فقط.

## الحالة
- واجهة المتجر: المسار /.
- لوحة متابعة الدفع: /dashboard (تتطلب تسجيل دخول الإدارة).
- إدارة المنتجات: /admin/catalog (تتطلب تسجيل دخول الإدارة).
- كتالوج المنتجات يبدأ فارغاً؛ لا توجد أسعار أو منتجات افتراضية مخترعة.
- الخادم يحسب الأسعار من سجلات الكتالوج، ولا يعتمد على المبلغ المرسل من المتصفح.
- checkout لا ينشئ جلسة لدى Tamara أو Tabby ولا يجمع أي مبلغ.
- التخزين الحالي في ذاكرة العملية فقط؛ لا يوجد ربط PostgreSQL فعلي في هذه المرحلة.
- ملف migrations/0001_beefitness_store.sql مخطط مقترح فقط ولا يجوز تطبيقه دون موافقة منفصلة.

## التشغيل
- npm install
- npm run check
- npm test
- npm start

## إعداد الإدارة
يلزم إعداد ADMIN_USERNAME وADMIN_PASSWORD_HASH وADMIN_SESSION_SECRET في بيئة التشغيل الآمنة. لا تحفظ الأسرار في GitHub ولا ترسلها في المحادثات.

## بوابات الدفع
تظل Tamara وTabby في preview. تفعيل sandbox أو live يتطلب عملاً مستقلاً للتحقق من API/webhooks، التخزين الدائم، idempotency، reconciliation، واختبارات المزود. لا تحول PAYMENT_MODE إلى live بناءً على هذا الفرع.

## قبل الإطلاق
اعتماد الكتالوج والأسعار والمخزون وسياسة الشحن والتوصيل والإرجاع والخصوصية والشروط ووسائل التواصل. ثم مراجعة أمنية واختبارات sandbox وموافقة مستقلة على أي ربط قاعدة بيانات أو نشر.
