# BeeFitness Store — Tamara & Tabby

متجر BeeFitness بواجهة عربية RTL، وكتالوج خادمي، وسلة ومعاينة طلبات. تكامل مزودي الدفع موجود على مستوى Sandbox adapters، بينما تظل رحلة العميل في وضع المعاينة حتى اعتماد بيانات التاجر المطلوبة.

## الحالة الحالية
- الواجهة: /.
- لوحة الدفع: /dashboard (تسجيل دخول الإدارة مطلوب).
- إدارة المنتجات: /admin/catalog (تسجيل دخول الإدارة مطلوب).
- لا توجد منتجات أو أسعار افتراضية؛ الكتالوج يبدأ فارغاً.
- التسعير يتم من بيانات الخادم، ولا يعتمد على مبالغ المتصفح.
- checkout يظل preview-only ولا ينشئ جلسة لدى Tamara أو Tabby.
- PostgreSQL اختياري ومغلق افتراضياً. يلزم STORE_PERSISTENCE=postgres مع DATABASE_URL معاً قبل أن يحاول التطبيق الاتصال.
- ملف migration مقترح فقط ولا يتم تطبيقه تلقائياً.
- اختبارات Sandbox تستخدم mock fetch ولا تتصل بمزودي الدفع.

## التشغيل والاختبار
- npm install
- npm run check
- npm test
- npm start

## إعداد الإدارة والأسرار
تُدار ADMIN_USERNAME وADMIN_PASSWORD_HASH وADMIN_SESSION_SECRET ومفاتيح مزودي الدفع داخل secret manager في بيئة التشغيل فقط. لا تضع قيماً حقيقية في Git أو تقارير الفحص.

## قبل تفعيل Sandbox
يلزم اعتماد حقول عنوان الشحن، وسياسة الشحن والضرائب والإرجاع، وروابط العودة والإشعار، وبيانات تقييم المخاطر المطلوبة من Tamara، ثم توفير مفاتيح Sandbox في مخزن الأسرار. لا توجد مدفوعات حقيقية أو نشر ضمن هذا الفرع.
